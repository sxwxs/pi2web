VOICE

Sotto dictation with pi2web

pi2web no longer processes audio. Sotto handles recording, recognition, and playback; pi2web only accepts text drafts.

2026-07-25pi2webPractical guide
On this pageHow it worksAuthorizationLimits

How it works

Sotto handles voice interaction and sends recognized text to POST /api/v1/draft on pi2web. Example body: {"text":"...","mode":"append","source":"sotto"}. The optional mode is append or replace. The browser inserts the text into the currently displayed composer for review and manual sending; it never automatically prompts an agent.

Configure speech in Sotto. pi2web no longer has a built-in microphone button, spoken summaries, or TTS/STT settings.

Authorization

Shell
pi2web --create-voice-token
pi2web --revoke-voice-token

The restricted voice token can only submit drafts and read system status; it cannot inspect or control agents. Point Sotto's services.pi2web.url at the intended backend and store the one-time token securely.

Limits

Drafts are buffered per backend in process memory (up to 50, for one hour) until the browser acknowledges insertion; they do not survive restarts. Drafts cannot select or switch sessions. Multiple browser tabs on the same backend may each insert a copy, so use one dictation tab. Spoken announcements belong to Sotto, not pi2web.
