01

本网站

pi2web.es2q.com 是一个纯静态站点，没有账号系统、评论、表单或订阅功能，也不使用任何第三方分析、广告或追踪脚本。

页面只加载同源的 CSS、JavaScript 和 SVG 图标，不加载外部字体或 CDN 资源。服务器可能按常规方式记录访问日志（IP、时间、请求路径、User-Agent），用于运维与安全排查。

02

pi2web 软件

pi2web 是运行在你自己机器上的开源软件。它不会把 Session、代码、Prompt 或 Agent 输出发送到本项目的网站或作者控制的任何服务。

软件本身不包含遥测、使用统计或崩溃上报。

03

本地保存的数据

~/.pi/remote-pi/remote-pi.dbWorkspace、Agent 与 Session 索引等服务端元数据（SQLite）。
~/.pi/remote-pi/auth.json配对码的 SHA-256 hash 及创建、轮换时间，文件权限 0600，不含明文。
~/.pi/agent/sessions/由 Pi 的 SessionManager 以 JSONL 保存的完整对话，由 Pi 管理而非 pi2web。
浏览器 localStorage服务地址、当前 Workspace/Agent 与事件游标；配对码只有在你明确确认后才会保存。
进程内存Terminal 会话与最近 512 KiB 输出，服务退出即释放。

获得配对码的人可以通过 Terminal 获得运行 pi2web 那个用户的 Shell 权限，因此配对码应当按凭据对待，只在可信设备上保存。

04

网络请求

默认配置下，pi2web 只监听 127.0.0.1，网络流量仅限本机浏览器与服务之间，以及 Pi 自身向你配置的模型 Provider 发起的请求。模型请求由 Pi 直接发出，pi2web 不代理、不缓存、不记录其内容。

05

可选的外部服务

  • 自动 Session 命名（默认开启）：一轮对话结束后，最近一次用户 Prompt 与 Agent 最终输出会被截断并提交到你配置的 OpenAI 兼容命名 endpoint（默认为 http://localhost:8313/，即本机）以生成 Session 名称。若你把 --session-name-base-url 指向远程服务，这部分会话内容会离开本机。可用 --session-naming off 关闭。
  • 邮件通知：只有在你配置 MailDispatch 后才会把通知内容提交到你指定的 endpoint。是否包含 Agent 回复与 Session 信息由你自己决定。
  • 语音摘要与识别：只有在你配置语音服务后，最终回复的摘要输入与录音才会发送到你指定的 endpoint。
  • 隧道与反向代理：若你使用 devtunnel、Cloudflare Tunnel 或自建代理，流量会经过对应服务商，请参考其自身的隐私政策。

除自动 Session 命名外，以上功能默认全部关闭；自动命名默认开启，且默认指向本机 endpoint。
