VOICE

Sotto 与 pi2web 语音草稿

pi2web 不再处理音频：录音、识别和播报由 Sotto 负责；pi2web 仅接收文字草稿。

2026-07-25pi2web实践指南
本文目录工作方式授权边界与限制

工作方式

Sotto 负责语音交互，并向 pi2web 的 POST /api/v1/draft 发送已识别的文字。请求体为 {"text":"...","mode":"append","source":"sotto"}；mode 可选 append 或 replace。网页将文字写入当前显示的输入框，供人检查、编辑、手动发送；绝不自动给 Agent 发消息。

语音能力由 Sotto 自行配置。pi2web 不再提供内置麦克风按钮、语音摘要、TTS 或 STT 配置选项。

授权

Shell
pi2web --create-voice-token
pi2web --revoke-voice-token

受限 voice token 只允许调用草稿接口及系统状态接口；不能读取或控制 Agent。请把 Sotto 的 services.pi2web.url 指向目标 Backend，并妥善保存只显示一次的 token。

边界与限制

草稿按 Backend 暂存在服务进程内（最多 50 条、1 小时），直到网页写入后确认；服务重启后不保留。它不会指定或切换会话。同一 Backend 的多个网页标签可能各自插入同一段文字，建议只开一个用于听写的页面。Sotto 的语音播报由 Sotto 自身负责，不经过 pi2web。
