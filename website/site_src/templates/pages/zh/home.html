开源 · 自托管 · 配对码保护

你的 Pi Coding Agent，
浏览器和手机都能接管。

pi2web 在你自己的开发机上运行 Pi Coding Agent，并通过一个受配对码保护的 HTTP/WebSocket 服务提供 Web UI 与 Android 原生客户端。会话、模型和代码都留在本机，只是多了一块屏幕。

阅读配置指南 在 GitHub 查看 ↗
$ npm install -g pi2web

pi2web 不提供模型，也不提供额度。 它复用本机 ~/.pi/agent 中已有的 Pi 模型配置与 Provider 认证；需要 Node.js 20.10 及以上版本。

WHY PI2WEB

把长时间运行的 Agent，
带到你手边的任何设备。

Agent 跑在开发机上最合理：代码、依赖和工具链都在那里。缺的只是一个可以随时接管的远程界面。

01

随时接管，不中断

浏览器和 Android 客户端连接同一个服务。离开电脑后继续跟进流式输出、追加指令、steer 或 abort。

02

默认只监听本机

默认绑定 127.0.0.1，访问需要手动输入配对码；服务端只保存配对码的 SHA-256 hash，并对失败尝试做指数退避限流。

03

断线可恢复

WebSocket 带 sequence 去重、断线指数退避和增量 replay/snapshot；Agent 元数据落在 SQLite，重启后按需重新加载。

HOW IT WORKS

一个进程，连接所有客户端与本机 Pi。

pi2web 使用真实的 @earendil-works/pi-coding-agent SDK 启动 Agent，并复用 Pi CLI 的模型、认证与设置目录。

MORE THAN A VIEWER

远程操作需要的细节，都已经补齐。

终端、文件、通知、语音、邮件与持久化，一个进程即可提供，无需再部署别的服务。

AGENTS

多 Workspace、多 Agent 并行

为不同仓库创建 Workspace，在同一列表中管理 Agent 与 Terminal。Agent 元数据保存在 SQLite，重启后为 unloaded 状态，真正需要时才按需启动 Pi Session。

TERMINAL

交互式终端

基于 node-pty 的真实 Shell，支持输入、resize、输出快照与刷新重连；每个服务进程最多 8 个终端。

service-api runningweb-client 12mbash · ~/code 1h
VOICE

语音摘要与语音输入

Agent 结束后用摘要 LLM 生成短播报并流式 TTS；配置 STT 模型后还能用麦克风输入 Prompt。

语音功能默认关闭
MAIL

完成邮件通知

通过 MailDispatch 在任务结束时发邮件，可设置聚合等待时间，并选择是否包含回复内容与会话信息。

PERSISTENCE

可靠的元数据存储

WAL 模式的 SQLite 保存 Workspace、Agent 与 Session 索引；完整对话仍由 Pi 的 SessionManager 以 JSONL 管理。

SECURITY FIRST

把这项服务当成一把 Shell 钥匙。

Terminal 是以 pi2web 进程用户身份运行的完整宿主机 Shell，Workspace 路径只决定初始 cwd，并不是沙箱。请通过 SSH 隧道、Tailscale 或带访问控制的 HTTPS 反向代理访问，不要把端口直接暴露到公网。

STEP 01

全局安装

需要 Node.js 20.10+。安装时会准备 better-sqlite3 与 node-pty 原生模块。

npm install -g pi2web
STEP 02

启动服务

首次启动时终端会显示一次配对码，务必立刻保存。

pi2web --host 127.0.0.1 --port 11318
STEP 03

打开并配对

访问 http://127.0.0.1:11318，手动输入配对码，然后添加第一个 Workspace。

pi2web --rotate-access-token
